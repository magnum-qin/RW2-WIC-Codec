# Support

## Before opening an issue

1. Read [TROUBLESHOOTING.md](TROUBLESHOOTING.md).
2. Confirm you are using the latest release.
3. Reproduce the problem with `TestDecoder.exe` or `TestExif.exe` when possible.
4. Check whether the problem is already reported.

## Bug reports

Use the bug report form and include the Windows version, codec version, camera model, exact reproduction steps, and relevant logs.

RW2 files may contain location, camera serial number, author, or other personal metadata. Remove sensitive metadata or use a private transfer channel before sharing a sample.

## Questions and feature requests

Use GitHub Issues. Support is provided on a best-effort basis; no response-time guarantee is offered.
